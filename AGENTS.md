# Руководство по репозиторию

## Цель и текущее состояние

Проект готовит эксперимент для статьи «Когда окупается перестроение хеш-таблицы после массового удаления ключей?». Сравниваются два состояния одной реализации с открытой адресацией и двойным хешированием.

В корне находятся план исследования (`README.md`), лицензия (`LICENSE`), объявления (`mod.h`) и операции с таблицей (`mod.cpp`). В `main.cpp` реализовано сравнение времени поиска на четырёх наборах. Данные генерируются в памяти. Автоматические тесты, отдельный подсчёт проб и график полного времени запланированы. Системы сборки пока нет.

Лабораторную `/Users/daniildyatlov/develop/university/CPP/lb31` используй только для чтения. Ориентиры в коде — `hash_double`, `find_open_index`, `insert_open` и `delete_open`. Метод цепочек в сравнение не входит.

## Порядок эксперимента

1. Заполни 80 % ячеек различными ключами и удали половину вставленных ключей. Первую таблицу оставь с метками `DELETED`. Для второй перенеси сохранившиеся записи в чистую таблицу той же ёмкости.
2. До замеров поиска проверь равенство ёмкостей и множеств ключей. Отдельно проверь случай коллизии, когда поиск сохранившегося ключа проходит через ячейку с меткой `DELETED`.
3. Подготовь серии с долей неуспешных поисков 10 %, 50 % и 90 %. В каждом сценарии обе таблицы получают одинаковую последовательность запросов.
4. Измеряй отдельно время перестроения и время каждой серии поиска. Генерацию данных и проверки корректности выполняй вне замеров. Среднее число проверенных ячеек на запрос считай отдельным прогоном. Повторяй замеры на нескольких наборах ключей, чередуя порядок запуска таблиц.

## Оценка окупаемости

Для серии длины `N` вычисли среднюю экономию на запросе: `Δ = (время поиска с метками − время поиска после перестроения) / N`. Если экономия положительна и превышает разброс измерений, оцени порог как `время перестроения / Δ`. Используй одинаковые единицы времени.

Проверь оценку на сериях разной длины. Сравни время поиска с метками с суммой времени перестроения и последующего поиска. Вывод для каждого сценария подкрепи замерами и их разбросом. Если в исследованном диапазоне окупаемость не наблюдалась, укажи это.
